# ☕ 3D-Визуализатор барной стойки и кофейни

Интерактивный 3D-проект кофейни с детальной барной стойкой, разработанный на базе Three.js (WebGL).

## 🚀 Онлайн-демонстрация
[👉 Открыть 3D-визуализатор](https://maksimeryshev609-ship-it.github.io/coffee-counter-3d/)

---

## ✨ Возможности
* **Полная 3D-модель помещения и стойки**:
  - Точные габариты барной стойки (2050×1400×1100 мм) с рабочими зонами, полками, нишами и вырезами.
  - Скос 45° с примыканием к наклонной стене помещения.
  - Дверца для бармена в проходе.
  - Задняя линия стеллажей с оригинальным меню «АРОМА КОФЕ».
* **Интерактивное управление**:
  - Смена материалов: Дерево (Орех / Дуб), Чёрный матовый металл, Белый мрамор, Бетон.
  - Переключение наполнения: кофемашина, кофемолка, бутылки с сиропами, посуда, стаканчики.
  - Режим отображения габаритных линий и размеров (Ш / Г / В).
  - Быстрые ракурсы камеры: Общий вид, Зона гостей, Рабочая зона бариста, Вид сверху, Витрина.
* **Реализм и освещение**:
  - Режим «Ultra-HD»: сглаживание, реалистичные тени (PCF Soft Shadows), мягкая подсветка рабочих зон и полок.
  - Зал со столиками, направленными стульями, стеклянным фасадом и напольными комнатными растениями в кадках (монстера / замиокулькас).
* **Мобильная поддержка**:
  - Полная поддержка тач-управления (вращение пальцем, зум щипком) на iOS и Android.
